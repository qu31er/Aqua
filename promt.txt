Ты — Senior Full-Stack разработчик и UI/UX дизайнер с экспертизой в создании нагруженных систем. Твой стек: Python (FastAPI/WebSockets), JavaScript/TypeScript, HTML5, CSS3.

Задача: Создать многофункциональный веб-мессенджер под названием "Aqua". Дизайн должен быть строгим, минималистичным, в морской тематике (используй цветовую палитру из прикрепленного логотипа: светло-голубой фон, темно-синие и бирюзовые акценты). Все иконки должны быть реализованы исключительно через инлайн SVG (без сторонних библиотек и растровых изображений).

Разделение на этапы: Не выдавай весь код сразу. Работай пошагово. После каждого этапа останавливайся и жди моего подтверждения (например, "Продолжай").

Вот список задач, которые нужно реализовать:

Этап 1: Архитектура, Бэкенд (Python) и Авторизация

· Напиши серверную часть на Python с использованием FastAPI и WebSockets для работы в реальном времени.
· Опиши структуру базы данных (SQLite для MVP или PostgreSQL) для пользователей, чатов и сообщений.
· Упрощенная регистрация: Реализуй систему входа/регистрации, где требуется только имя пользователя (username) и пароль. Никаких email или номеров телефонов.
· Валидация пароля: Жестко задай проверку. Пароль должен содержать минимум 8 символов, включать хотя бы одну строчную латинскую букву (a-z) и хотя бы одну цифру (0-9). Напиши функцию валидации на стороне сервера и возвращай понятную ошибку при несоответствии.
· Реализуй API-эндпоинты: регистрация/авторизация (JWT), получение истории сообщений, создание чатов, загрузка медиафайлов.

Этап 2: Каркас, UI, Адаптивность и Анимации (HTML/CSS)

· Создай базовый index.html.
· Напиши CSS (используй CSS-переменные для цветов Aqua). Дизайн: минимализм, скругленные углы, тени как на логотипе.
· Сверстай сетку: боковая панель (список чатов) + основная область (окно переписки). Сверстай формы входа и регистрации.
· Адаптивность (Mobile-First / Responsive): Реализуй адаптацию под мобильные устройства, планшеты и десктопы. На мобильных устройствах боковая панель должна скрываться, а окно чата занимать 100% экрана (с кнопкой "Назад"). Используй Flexbox/Grid, медиа-запросы (@media) и относительные единицы измерения (vw, vh, rem).
· Анимации и переходы (UX/UI): Добавь плавные CSS-анимации (@keyframes, transition) для появления сообщений, нажатия на кнопки, открытия/закрытия модальных окон, состояния "печатает...". Обязательно учти prefers-reduced-motion.

Этап 3: SVG Иконки и Элементы Медиа-интерфейса

· Сгенерируй чистый код SVG для базовых иконок в стиле минимализм (толщина 1.5px - 2px, цвет #005A8D): "Отправить", "Прикрепить", "Настройки", "Поиск", "Профиль", "Голосовое сообщение", "Смайлик", "Меню/Бургер", "Закрыть", "Назад".
· Дополнительные SVG для медиа: Сгенерируй иконки для кастомного файлового менеджера и редактора: "Папка", "Файл", "Видео", "Фото", "Обрезать", "Повернуть", "Кисть/Рисование", "Текст", "Галочка (Готово)".
· Подготовь CSS-классы для микроанимаций иконок при наведении и нажатии.

Этап 4: Фронтенд-логика и Тактильность (JavaScript)

· Напиши JS-код для подключения к WebSocket серверу.
· Реализуй отправку и мгновенное получение сообщений без перезагрузки страницы (AJAX/Fetch + WS).
· Клиентская валидация: Добавь проверку полей ввода пароля на фронтенде (регулярные выражения) с визуальной индикацией до отправки на сервер.
· Добавь обработку нажатия на Enter для отправки (и Shift+Enter для переноса строки).
· Тактильная отдача (Haptic Feedback): Реализуй функцию вызова вибрации через navigator.vibrate() (с проверкой на поддержку браузером) для отправки/получения сообщений и нажатия на важные кнопки UI.
· Обработка мобильных событий: Учти особенности работы с touch-событиями на сенсорных экранах.

Этап 5: Функционал уровня Telegram

Реализуй и опиши логику для следующих фич:

1. Статусы: Онлайн/Оффлайн, "печатает...".
2. Кастомный файловый менеджер (Внутреннее окно выбора): Вместо системного окна <input type="file"> реализуй модальное окно внутри мессенджера. Оно должно отображать последние загруженные пользователем медиафайлы, папки и возможность выбрать файл с устройства (через скрытый input). Дизайн окна — в стиле Aqua, с сеткой превью.
3. Редактор медиа (Фото и Видео): Перед отправкой выбранного фото или видео открывается окно предпросмотра/редактирования.
   · Для фото: Возможность кадрирования (crop), поворота, рисования поверх (кисть), добавления текста и применения базовых фильтров.
   · Для видео: Обрезка (trim) начала и конца, выбор обложки (thumbnail), предпросмотр.
   · Реализация: Используй HTML5 Canvas API для обработки фото и <video> + Canvas для кадров видео. Результат редактирования конвертируй в Blob/File и отправляй через FormData.
4. Реакции: Возможность ставить эмодзи-реакции на сообщения (с адаптивным контекстным меню для мобильных).
5. Голосовые сообщения: Запись с микрофона (MediaRecorder API) и отправка (с анимированной волной звука).
6. Безопасность: Шифрование передаваемых данных (опиши базовый алгоритм) и хеширование паролей (например, bcrypt) на сервере.
7. добавь при входе заставку (файл start.mp4)
8. иконка — файл icon.png

Требования к коду:

· Код должен быть чистым, модульным и с комментариями на русском языке.
· Никакого спагетти-кода. Разделяй логику и представление.
· Кроссплатформенность: Верстка и анимации должны корректно отображаться во всех современных браузерах (Chrome, Safari, Firefox, Edge), включая мобильные версии (учти префиксы -webkit- для Safari).
