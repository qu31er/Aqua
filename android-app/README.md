# Android-приложение Aqua (APK)

Тонкая оболочка на Capacitor: открывает ваш сервер Aqua в приложении, поддерживает микрофон для голосовых.
APK собирается автоматически в GitHub Actions — ничего устанавливать на компьютер не нужно.

## Как собрать
1. На GitHub: репозиторий → **Settings → Secrets and variables → Actions → Variables → New repository variable**:
   имя `AQUA_URL`, значение — адрес вашего сервера, например `https://aqua-production.up.railway.app` (без `/` в конце).
2. Вкладка **Actions → «Сборка Android APK» → Run workflow** (адрес можно ввести и прямо в форме запуска).
3. Через 5–10 минут APK появится в разделе **Releases → «Aqua APK» → Aqua.apk** (и в артефактах запуска).
4. Откройте Releases с телефона, скачайте `Aqua.apk`, разрешите установку из этого источника.

Это debug-сборка: ставится напрямую, но не подходит для публикации в Google Play (для неё нужна подпись release-ключом).
Приложение загружает интерфейс с сервера, поэтому обновления сайта появляются в нём без пересборки APK.
